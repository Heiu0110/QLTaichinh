# Bank logo assets

MB Bank, VietinBank and Sacombank logos extracted without image modification from
`vietqr-zero@1.0.0` (`dist/esm/banks-data.js`, entries MB, ICB and STB).
Source: https://github.com/openhoangnc/vietqr (vietqr-zero package, MIT).
The bank names/logos identify the user's account choices; respective banks retain
their trademarks. No bank connection or endorsement is implied.

Only these three WebP images are included. No library code or dependency is used.
They are served locally and precached for offline use.
